API
  • v1/status.json — every carrier, current vs baseline
  • v1/suspensions.json — who stopped, when, for how long, and who came back
  • v1/alerts.json — suspended and reduced routes
  • v1/airlines/{ICAO}.json — one carrier, route by route
  • v1/airports/{ICAO}.json — one airport, who is still serving it
  • v1/firs.json — overflight counts per FIR
  • v1/advisories.json — EASA CZIB state
  • v1/health.json — data span, last runs, baseline readiness
